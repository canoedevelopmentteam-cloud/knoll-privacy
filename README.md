# Knoll privacy policy

https://canoedevelopmentteam-cloud.github.io/knoll-privacy/

- `index.html`: the whole policy in one self-contained file (no JavaScript, no trackers, no external fonts or images; inline CSS, light and dark).
- `.nojekyll`: serve the file as is.
